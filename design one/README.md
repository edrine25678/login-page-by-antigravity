# Animated Login & Registration Page

A sleek, responsive, dark-mode animated Login and Registration form featuring cyber-neon accents, a dynamic curved diagonal background transition, and staggered entrance/exit animations.

Inspired by modern frontend UI design and TikTok coding showcases ([@paulcodes4](https://www.tiktok.com/@paulcodes4)).

---

## ✨ Features

- **Split Dual-Panel Architecture**: Smoothly switches between Login and Registration states.
- **Curved Background Transition**: Rotated, skewed gradient overlay that sweeps across panels upon mode toggle.
- **Staggered Animations**: Uses CSS custom properties (`--li`, `--lo`) and `calc()` for cascading blur and slide-in effects.
- **Neon Orange Cyber Glow**: High-contrast dark theme with burning amber and neon-coral highlights (`#ff4e27`).
- **Interactive Underline Fields**: Floating labels with icon integration (Boxicons).
- **Responsive**: Adapts gracefully across desktop and mobile screens.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it with a local web server:

```bash
# Using Python
python -m http.server 5500

# Or open directly
start index.html
```
